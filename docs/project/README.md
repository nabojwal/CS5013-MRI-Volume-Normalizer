# Project Basis and Course Deliverables

This directory preserves the original academic scope of the
CS5013 MRI Volume Normalizer.

## Authority order

1. `PROJECT_PROPOSAL.pdf`
   - Original project scope and stakeholder-facing commitment.
   - De-identified repository copy.
   - Used as the primary source for final requirement traceability.

2. `../architecture/ARCHITECTURE-REVISION-1.0.md`
   - Current authoritative software architecture.

3. `../../DECISIONS.md`
   - Subsequent architecture decisions and clarifications.

Where these documents differ, the original project proposal defines the promised
product scope, while Architecture Revision 1.0 and accepted ADRs govern the
current technical implementation.

The repository copy of the proposal is intentionally de-identified. Patient
data, private correspondence, personal contact information, and research imaging
datasets must not be committed to Git.
