# Unresolved Decisions

The following decisions remain intentionally open:

- MRI spatial coordinate system and orientation convention.
- `Volume` voxel storage type, precision, and memory layout.
- DICOM series grouping rules.
- NIfTI library selection.
- Provenance serialization format.
- Structured error representation.
- UI concurrency and progress reporting mechanism.

These decisions must be resolved explicitly before the relevant implementation milestone. M4 does not silently choose any of them.
